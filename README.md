## 📁 How This Repo Works

```
leetcode/
├── 24-swap-nodes-in-pairs/
│   ├── README.md        # problem statement (auto-generated)
│   └── solution file    # my accepted solution
├── ...
└── README.md            # you are here
```

1. Solve the problem on LeetCode.
2. **LeetSync** pushes the accepted solution to this repo with its runtime and memory stats in the commit message.
3. Update the log above and keep the streak alive. 🔥

---

## 🎯 My Approach

1. **Understand** the problem and work through small examples by hand.
2. **Brute force first**, then optimize.
3. **Analyze** time and space complexity.
4. **Revisit** hard problems after a few days.
